# Промпт: создать или изменить историю

Прочитай `00-principles.md`, `01-glossary.md`, `02-stories.md`, `07-communication.md`, `09-naming.md`.

1. Найди исходный фрагмент и ближайшие термины в глоссарии.
2. Проверь, есть ли уже история с теми же ролью, объектом, действием, предусловиями и результатом.
3. Если нужного термина нет, предложи черновую запись глоссария; не используй свободную строку вместо ключа действия.
4. Создай атомарную историю из шаблона. Укажи отдельное предусловие, `so_that`, `motivation_type`, источник, приоритет и unresolved-пункты.
5. Если история содержит несколько независимых целей, разбей её или объяви сценарий со ссылками `composed_of`.
6. Проверь покрытие источника и связанные REQ/CON. Если смысл подтверждён пользователем, зафиксируй контекст подтверждения, но не помечай техническую проверку пройденной.

Выход: список файлов, причина изменений, результат проверки ссылок и открытые вопросы.
