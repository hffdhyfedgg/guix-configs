# Исходное видение

Сохраняйте здесь оригинальное видение, сообщения и принятые решения. Не редактируйте исходные цитаты так, чтобы изменялся их смысл; уточнения добавляйте отдельными датированными разделами.

Для каждого устойчивого фрагмента используйте ID `SRC-NNN` или заголовок-якорь. Номер строки допустим как подсказка, но не как единственный адрес. См. `design_docs/07-communication.md`.
