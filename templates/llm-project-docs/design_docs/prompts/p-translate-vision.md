# Промпт: транслировать видение

## Цель

Предложить трассируемую формализацию выбранных фрагментов `design/human/`, не подменяя намерение человека собственной интерпретацией.

## Перед началом

Прочитай `00-principles.md`, `01-glossary.md`, `02-stories.md`, `07-communication.md` и `09-naming.md`.

## Действия

1. Укажи конкретные исходные фрагменты/ID источника.
2. Классифицируй каждый фрагмент: утверждение, предпочтение/узнавание, запрет, диспозиция, становление или контекст.
3. Предложи записи глоссария и/или истории со статусом `draft`.
4. Для каждой интерпретации приведи пример-свидетель, контрпример/неоднозначность и допущения.
5. Не заполняй пробелы выдуманными решениями. Создай список уточнений только для вопросов, где решение зависит от человека.
6. Обнови `design/trace/coverage.yaml`: каждое намерение покрыто либо имеет disposition и обоснование.

## Выход

Предложенные файлы/диффы, список неоднозначностей и вопросов, матрица покрытия источника, проверки ссылок. Не выставляй `confirmed` без фактического подтверждения.
